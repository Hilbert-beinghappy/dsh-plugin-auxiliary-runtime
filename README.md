# dsh-plugin-auxiliary-runtime

Community auxiliary-model runtime for DeepSeek Harness. It keeps Agent-loop usage in the official `tokenUsage` projection and owns a separate durable auxiliary ledger. Consumers receive provenance-preserving `official`, `auxiliary`, and `combined` usage values.

The initial implementation is under development on `codex/auxiliary-runtime`. See [docs/task-book.md](docs/task-book.md) for the normative contract.
